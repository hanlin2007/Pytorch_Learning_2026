# 综合实战3：深度学习竞赛优化全流程

深度学习竞赛优化并不是把所有技巧一次性堆进模型，而是围绕可靠的验证方案持续进行实验：先跑通 Baseline，再定位瓶颈，每次只改变一个变量，最后使用集成与测试时增强冲击更高分数。

## 一、竞赛实验的基本闭环

一套稳定的竞赛流程通常包含以下步骤：

1. 明确任务类型和官方评估指标；
2. 划分能够代表测试集分布的验证集；
3. 建立简单、可复现的 Baseline；
4. 分析错误样本，判断过拟合、欠拟合或分布偏移；
5. 通过消融实验验证单项改动；
6. 保存实验配置、随机种子、模型权重和验证结果；
7. 在单模型稳定后进行 TTA、K-Fold 和模型集成。

> 核心原则：本地验证方案是否可信，往往比单次排行榜分数更重要。

## 二、数据层面的优化

### 2.1 数据增强

数据增强通过构造合理的样本变化，减少模型对训练集细节的记忆。

- 基础增强：随机翻转、旋转、裁剪、缩放和色彩抖动；
- MixUp：按比例混合两张图像及其标签；
- CutMix：将一张图像的局部区域粘贴到另一张图像；
- Mosaic：将四张图像拼接，常用于目标检测；
- 任务定制增强：根据真实采集过程模拟噪声、模糊或亮度变化。

增强必须符合任务语义。例如数字识别中随意垂直翻转可能改变类别，医学图像也不能默认使用所有自然图像增强。

```python
from torchvision import transforms

train_transform = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.8, 1.0)),
    transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(brightness=0.2, contrast=0.2),
    transforms.ToTensor(),
    transforms.Normalize(
        mean=(0.485, 0.456, 0.406),
        std=(0.229, 0.224, 0.225),
    ),
])
```

MixUp 的核心公式为：

\[
\tilde{x}=\lambda x_i+(1-\lambda)x_j,\qquad
\tilde{y}=\lambda y_i+(1-\lambda)y_j
\]

```python
import numpy as np
import torch

def mixup_batch(images, labels, alpha=0.4):
    lam = np.random.beta(alpha, alpha)
    index = torch.randperm(images.size(0), device=images.device)
    mixed_images = lam * images + (1 - lam) * images[index]
    return mixed_images, labels, labels[index], lam

def mixup_loss(criterion, logits, target_a, target_b, lam):
    return lam * criterion(logits, target_a) + (1 - lam) * criterion(logits, target_b)
```

### 2.2 清洗、标准化与类别不平衡

训练前应检查重复样本、错误标签、缺失数据、异常尺寸和损坏文件。输入标准化可以让梯度尺度更稳定，加快收敛。

类别不平衡可采用以下方法：

- 对少数类过采样或对多数类欠采样；
- 使用 `WeightedRandomSampler` 改变采样概率；
- 为交叉熵设置类别权重；
- 使用 Focal Loss，使模型更加关注难分类样本。

```python
import torch.nn as nn

class_weights = torch.tensor([1.0, 2.5, 1.2], device=device)
criterion = nn.CrossEntropyLoss(weight=class_weights)
```

SMOTE 更适合表格特征，不能简单地把它直接套在原始图像像素上。

### 2.3 测试时增强（TTA）

TTA 对同一测试样本生成多个合法视图，再平均各视图的预测概率。它通常能带来小幅而稳定的提升，但也会增加推理时间。

```python
@torch.no_grad()
def tta_predict(model, images):
    model.eval()
    logits_original = model(images)
    logits_flipped = model(torch.flip(images, dims=[3]))
    probs = (
        logits_original.softmax(dim=1)
        + logits_flipped.softmax(dim=1)
    ) / 2
    return probs
```

### 2.4 伪标签

伪标签使用当前最优模型预测无标签数据，将高置信度结果加入训练集。建议：

1. 只选择高置信度样本；
2. 为伪标签损失设置较小权重；
3. 控制各类别伪标签数量，避免错误被不断放大；
4. 仅根据比赛规则允许使用的数据进行训练。

## 三、模型架构层面的优化

### 3.1 Backbone 与注意力机制

更换特征提取主干往往是高收益改动。CNN 可尝试 ResNet、ResNeXt、EfficientNet；数据量和算力允许时，也可以尝试 ViT 等视觉 Transformer。

SE、CBAM 等注意力模块可以加强通道或空间特征，但新模块并不保证必然提升，仍需通过验证集和消融实验判断。

### 3.2 预训练与微调

ImageNet 预训练权重能够提供通用视觉特征，尤其适合中小型数据集。常用微调过程为：

1. 替换分类头；
2. 冻结主干，仅训练分类头；
3. 解冻部分或全部主干；
4. 使用差分学习率：底层学习率小，顶层学习率大。

```python
optimizer = torch.optim.AdamW([
    {"params": model.backbone.parameters(), "lr": 1e-5},
    {"params": model.classifier.parameters(), "lr": 1e-3},
], weight_decay=1e-4)
```

### 3.3 模型集成

- Bagging：融合相同架构在不同随机种子或数据划分下训练的模型；
- 异构集成：融合 CNN、ViT 等不同架构；
- 加权平均：按照验证集表现为模型分配权重；
- Stacking：使用基模型输出训练元模型。

分类任务通常平均概率而不是平均类别编号：

\[
p=\sum_{m=1}^{M}w_m p_m,\qquad \sum_{m=1}^{M}w_m=1
\]

集成模型之间的误差差异越大，融合收益通常越明显。

## 四、训练过程层面的优化

### 4.1 损失函数

- 交叉熵：多分类任务的标准 Baseline；
- Focal Loss：缓解类别不平衡并关注困难样本；
- Label Smoothing：防止模型对标签过度自信；
- 任务专用损失：目标检测中还可根据模型考虑 GHM 等方法。

```python
criterion = nn.CrossEntropyLoss(label_smoothing=0.1)
```

### 4.2 优化器与学习率

- AdamW：对初始学习率相对不敏感，适合快速建立 Baseline；
- SGD + Momentum：通常需要更多调参，但可能获得更好的泛化；
- Cosine Annealing：让学习率按余弦曲线衰减；
- OneCycleLR：先升后降，适合固定训练轮数；
- ReduceLROnPlateau：验证指标停滞时降低学习率；
- Warmup：训练初期逐步增大学习率，减少不稳定。

```python
optimizer = torch.optim.AdamW(
    model.parameters(), lr=3e-4, weight_decay=1e-4
)
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer, T_max=epochs
)
```

注意调度器的调用时机：按 epoch 更新的调度器通常放在一轮训练之后，而 `ReduceLROnPlateau` 需要传入验证指标。

### 4.3 正则化

- Weight Decay：抑制参数过大；
- Dropout：训练时随机屏蔽部分神经元；
- Stochastic Depth：随机跳过部分残差块；
- Early Stopping：验证指标长期不提升时停止训练。

实践中通常不对偏置和归一化层参数应用权重衰减，可通过优化器参数组单独配置。

### 4.4 显存与训练效率

梯度累积可使用多个小批次模拟大批次：

```python
accumulation_steps = 4
optimizer.zero_grad()

for step, (images, labels) in enumerate(train_loader):
    with torch.autocast(device_type="cuda", dtype=torch.float16):
        logits = model(images)
        loss = criterion(logits, labels) / accumulation_steps

    scaler.scale(loss).backward()

    if (step + 1) % accumulation_steps == 0:
        scaler.step(optimizer)
        scaler.update()
        optimizer.zero_grad()
```

混合精度训练结合 `float16` 与 `float32`，可以减少显存占用并提升 GPU 训练速度。实际代码还应处理最后不足 `accumulation_steps` 的批次，并在需要时进行梯度裁剪。

## 五、验证、后处理与提交

### 5.1 选择正确的验证方案

- 普通随机划分：适合独立同分布样本；
- Stratified K-Fold：分类任务中保持类别比例；
- Group K-Fold：同一用户、患者或视频的样本不能跨训练集和验证集；
- 时间序列划分：必须按时间先后验证，避免未来信息泄漏。

K-Fold 能更稳定地评估模型，也可以直接产生多个模型用于集成，但训练成本约为单次训练的 K 倍。

### 5.2 对抗验证

将训练集标记为 0、测试集标记为 1，再训练一个分类器区分二者。如果分类器 AUC 很高，说明训练集和测试集存在明显分布差异，需要进一步检查采集时间、设备、来源或预处理差异。

### 5.3 阈值与概率校准

二分类和多标签任务不一定使用固定的 0.5 阈值，应只在验证集上搜索阈值，不能利用测试标签。Temperature Scaling 可校准置信度，使不同模型的概率在集成时更可比较。

### 5.4 提交流程检查

提交前检查：

- 样本 ID、行数和顺序是否正确；
- 类别索引是否与赛题定义一致；
- 是否存在 `NaN` 或无穷值；
- 预测概率范围及每行概率和是否合理；
- 随机种子、代码版本和模型权重能否复现。

## 六、推荐的优化优先级

| 阶段 | 重点工作 | 目标 |
| --- | --- | --- |
| 1. Baseline | 跑通训练、验证、推理、提交 | 得到可信起点 |
| 2. 数据检查 | 清洗、划分、基础增强 | 排除泄漏与脏数据 |
| 3. 单模型优化 | 预训练、损失、学习率、正则化 | 提升模型上限 |
| 4. 稳健评估 | K-Fold、错误分析、消融实验 | 确认提升真实有效 |
| 5. 冲榜阶段 | TTA、伪标签、模型集成、阈值优化 | 获取最后的增益 |

建议使用实验表记录每次改动：

| 实验 | 唯一改动 | 验证分数 | 训练成本 | 结论 |
| --- | --- | --- | --- | --- |
| Baseline | ResNet + CrossEntropy | - | - | 基准 |
| Exp-01 | 增加 MixUp | - | - | 待验证 |
| Exp-02 | 改为 AdamW + Cosine | - | - | 待验证 |

## 七、总结

深度学习竞赛优化是一项系统工程。最可靠的路线是：

1. 用简单配置建立可复现的 Baseline；
2. 通过错误分析判断主要瓶颈；
3. 优先尝试数据增强、预训练和学习率等高收益方案；
4. 每次只改变一个变量，记录消融实验；
5. 在单模型稳定后再使用 K-Fold、TTA、伪标签和模型集成。

最终成绩不仅取决于模型结构，也取决于数据质量、验证设计、实验管理和提交细节。稳定的实验闭环，才是持续提升成绩的关键。
